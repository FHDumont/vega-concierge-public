# Returns and Refunds

## Return window

You have **{{REFUND_WINDOW_DAYS}} days** from the delivery date to request a return for any reason. The {{REFUND_WINDOW_DAYS}}-day window starts the day the carrier marks the order as delivered, not the day you placed it. Requests made after day {{REFUND_WINDOW_DAYS}} are outside the window and cannot be refunded automatically.

## Which orders can be returned

Only orders already marked as **delivered** can be returned. Orders still pending, paid, or in transit cannot be returned yet — wait for delivery, or cancel the order instead. Orders that already failed were never charged, so there is nothing to refund.

## Refund amount

An approved return is refunded for the **full order total**, including what you paid for shipping. Vega does not charge a restocking fee and does not deduct anything for return postage. There are no partial refunds for a full-order return.

## How long the refund takes

Once the return is approved, the refund is issued to the original payment method. Card refunds usually appear within 5 to 10 business days, depending on your bank. Pix refunds are typically same-day.

## Condition of the item

Returned items should come back in usable condition, with all included accessories, cables, and packaging when possible. Items damaged in transit are always covered and never count against this rule — report transit damage and we handle it as a claim, not a return.

## Exchanges versus returns

Vega processes returns as refunds to the original payment method. If you want a different size, color, or product, place a new order after the refund is issued. We do not ship replacement items before the original is received.

## How to start a return

Open your order in **Purchase history**, select **Request return**, and follow the prompts. You will receive a prepaid return label by email within one business day. Drop the package at any authorized carrier location and keep the tracking number until the refund posts.
